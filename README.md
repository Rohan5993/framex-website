# FrameX website

Homepage for FrameX, the Authority-to-Pipeline System for B2B tech companies.

A single static page: `index.html` (HTML, CSS and vanilla JavaScript, no build step).
Fonts load from Google Fonts: Newsreader, Schibsted Grotesk and Spline Sans Mono.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

GitHub Pages: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.
